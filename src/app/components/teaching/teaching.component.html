Teaching

Most of my teaching is done in the Electronics, Electrical Energy and Automation (EEEA) Licence (Bachelor) program and in the Data Science Master program at the University of Rouen Normandy. I also give lectures on Machine Learning topics at INSA Rouen Normandie and ESITech

Machine learning theory and algorithms

Master "Data Science" - first year students

Fundamental theoretical concepts of machine learning in general, as well as the most emblematic generalist methods (linear regression, logistic regression, linear and kernel SVM, etc.).

Web interface design

Master "Data Science" - first year students

GUI layout design using web technologies: How to use HTML/CSS technologies to create web layouts for GUI, with an emphasis on modern responsive web design techniques.

Client-side web programming

Master "Data Science" - first year students

Introduction to Javascript programming for implementing dynamic behaviour (e.g. user interaction) in Web documents. Focus on the use of the main JavaScript web APIs (DOM, Fetch, Event) and on the Angular framework.

Server-side web programming

Master "Data Science" - second year students

Server-side web programming with Jakarta EE (formerly Java EE) technologies. Describe the various server programming techniques in a conceptual and technical manner, illustrated by concrete examples.

Random Forest and Boosting

INSA "ITI department" - fourth year students

Introduction to Ensemble Learning and detailed explanations on Random Forest and (Gradient) Boosting techniques.
